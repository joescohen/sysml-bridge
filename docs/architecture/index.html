The pipeline, end to end

One spine runs the whole system: raw inputs become proposed elements, a human approves them, they land in a canonical IR, skills build the model through the MCP server, the serializer emits SysML v2 text, a local grammar gate must pass, and only then does it go to Cameo — with static figures rendered alongside. Three layers, one seam

Strict boundaries. The natural-language layer never touches files or APIs directly — it goes through the MCP server, which is the only component that knows where the model physically lives. That single seam is what makes Cameo portability a configuration change instead of a rewrite.

Model backend: file-native store — diffable JSON on disk, no server default

Key principle. Skills never talk to files or the API directly — they go through the MCP server. Because that server is the only thing that knows where the model lives, pointing the whole stack at Cameo at work is a one-line config change (SYSML_BRIDGE_BACKEND=smaps), not a rewrite.

From documents to a trustworthy IR

Two corpus-driven lanes feed the model — one reads prose, one reasons over the graph — but neither writes anything on its own. Both converge on a human approval gate, and only approved items are layered into the canonical IR.

Two gates keep it honest

"It parsed clean" is not "it imported." The local validator checks grammar; Cameo checks semantics. Both have to pass, and they catch different classes of error — so the serializer is held to the vendored grammar, never to memory.

Serializer → grammar gate → Cameo

Grammar gate catches (local, fast)

  • Malformed SysML v2 syntax — the committed ANTLR parser rejects it.
  • Illegal verify placement — legal only inside a verification objective body (R3).
  • Structural notation errors before they ever reach Cameo.

Semantic gate catches (Cameo only)

  • A Definition used as a trace operand — "cannot be cast to Feature" (R4). Parses clean, fails import.
  • Duplicate names, unresolved types, :> to a definition.
  • The 500 "major element" cap — handled by emitting a lean, usages-only projection.
R1
The grammar is the source of truth
The serializer conforms to the vendored .g4 — never to recalled syntax.
R2

R4

satisfy / allocate / verify operands must be usages (Features). Cameo rejects Definitions.

Materializing in Cameo

The one move that matters: Synchronize, not Save. Paste the .sysml into Cameo's Textual Editor and press Alt+S — Cmd+S only saves the project and creates no elements. Synced elements get a [$N] display id.
